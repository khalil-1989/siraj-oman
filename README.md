# صحيفة سراج عُمان — أكواد GitHub Pages

منصة عربية ثابتة دون تسجيل دخول، أو قاعدة بيانات داخل المشروع، أو متطلبات تثبيت. تتضمن 25 عددًا متتابعًا من الصور المرفقة (1 إلى 25)، بما فيها العدد الثالث: تراث وثقافة — مواقع أثرية.

## تشغيل سريع

افتح `index.html` في المتصفح، أو استخدم خادمًا محليًا:

```bash
python -m http.server 8000
```

ثم افتح http://localhost:8000 . ميزة نسخ الرابط تحتاج HTTPS أو localhost وقد لا تعمل عند فتح ملف مباشرة.

## الرفع إلى GitHub

1. أنشئ مستودعًا جديدًا؛ لا يحتاج القراء حساب GitHub لزيارة الموقع المنشور.
2. فك ضغط الملف وارفع **محتويات** مجلد `siraj-newspaper` إلى جذر المستودع، بما فيها `assets`؛ يجب أن يكون `index.html` في الجذر.
3. من Settings ثم Pages اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
4. انتظر إتمام نشر Pages ثم افتح الرابط الذي يظهر. لا ترفع ملف ZIP وحده.
5. عند تحديث المحتوى ارفع التعديلات إلى الفرع نفسه.

يمكن رفع الملفات ببرنامج GitHub Desktop أو Git. ملفات الصور منفردة أقل من حد الرفع الشائع عبر واجهة الويب، لكن رفعها دفعة واحدة قد يكون أبطأ. تحقق من دعم Pages في نوع المستودع وخطتك.

توثيق GitHub الرسمي:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## المحتوى والتصميم

- صور الصفحات مضمّنة كاملة بصيغة WebP بضغط بلا فقد، مع إبقاء العددين 3 و13 والأعداد 21–25 بصيغة PNG الأصلية؛ لا يعاد رسم النصوص أو تغيير بياناتها.
- الغلاف المصغّر محسّن للسرعة؛ القارئ يفتح النسخة الكاملة.
- النص داخل الصور ليس HTML قابلًا للبحث أو لقارئ الشاشة؛ البحث المتاح برقم العدد وعنوانه فقط. لم تُنتج نسخة نصية مدققة لجميع المقالات.
- العناوين في `issues.js` للتنقل، أما جميع بيانات الصحيفة فتظهر في الصورة الأصلية.
- أدوات التكبير، ملاءمة العرض، التنقل بين الأعداد المتاحة، الرابط المباشر، البحث والترتيب تعمل دون خدمات خارجية.
- رابط العدد مثل `https://USER.github.io/REPO/#issue=10` ويمكن تحويله إلى QR لاحقًا.

## الانطباعات — الحالة الافتراضية

أزرار الانطباع تحفظ اختيارًا واحدًا لكل عدد **في متصفح القارئ فقط**، ويمكن تغييره. لا تدعي أنها ترسل إلى المشرف، ولا تعرض مجموعًا مزيفًا. مسح بيانات المتصفح يمسح هذه الاختيارات. لا توجد قاعدة بيانات للانطباعات أو لوحة إدارة مخفية.

لجمع الانطباعات دون إنشاء قاعدة بيانات خاصة بالمشروع:
1. أنشئ نموذجًا عامًا في خدمة نماذج تختارها (مثلاً Google Forms).
2. أضف حقول: رقم العدد، الانطباع، ملاحظة، واسم اختياري فقط عند الحاجة.
3. اضبطه ليقبل الردود دون تسجيل دخول، واختبر الرابط في نافذة خاصة. إعدادات حساب المدرسة قد تمنع الردود العامة؛ تحقق منها.
4. ضع رابط المشاركة HTTPS في `feedbackUrl` داخل `config.js`.
5. سيظهر زر يفتح النموذج؛ الردود تُحفظ لدى الخدمة الخارجية وليست في GitHub أو قاعدة بيانات المشروع. أزرار الاختيار المحلية لا تُرسل تلقائيًا إلى النموذج.

إذا كان الشرط هو عدم تخزين الانطباعات في أي مكان حتى لدى خدمة خارجية، فلا يمكن توفير حصر مركزي دائم للانطباعات.

## إحصاءات جميع الزائرين — ربط اختياري

الربط غير مفعّل افتراضيًا. لا توجد أرقام زوار وهمية. لتفعيله:
1. أنشئ حسابًا وموقعًا لدى https://www.goatcounter.com/ . الحساب مطلوب للمالك فقط؛ لا يسجل القراء الدخول.
2. ضع رمز موقعك فقط في `goatcounterCode`، مثل `my-newspaper`، دون رابط أو كلمة مرور.
3. تُسجل الواجهة الرئيسية وكل فتح لعدد بمسار مستقل في لوحة GoatCounter؛ افتح لوحة الخدمة الخاصة بك للاطلاع على الإحصاءات التقديرية.
4. لإظهار إجمالي مشاهدات الصفحات علنًا، فعّل “Allow adding visitor counts on your website” في الخدمة ثم اجعل `publicCounter: true`.
5. العداد العام يحصي **مشاهدات الصفحات** لا الأشخاص الفريدين، وقد يتأخر تحديثه حتى أربع ساعات. عدّ الأشخاص الفريدين تقريبي وتؤثر فيه حواجز التتبع والأجهزة المختلفة.
6. لا يمكن معرفة أسماء الزائرين تلقائيًا. لا تستخدم رموز API الخاصة أو كلمات مرور في أي ملف عام.
7. اختبر الإحصاءات بعد النشر: افتح الرئيسية وعددين، ثم راجع لوحة الخدمة. الخدمة قد تتجاهل localhost افتراضيًا.

هذه خدمة خارجية تحفظ إحصاءات التصفح لديها. مراجعة خيارات الخدمة وشروطها والتكاليف إن وجدت مسؤولية صاحب الحساب. يمكن تعطيلها بإفراغ الرمز. فشل الخدمة لا يمنع قراءة الصحيفة.

التوثيق:
https://www.goatcounter.com/help/js
https://www.goatcounter.com/help/visitor-counter

## الملفات

- `index.html`: واجهة المنصة والقارئ.
- `styles.css`: الألوان والتجاوب.
- `app.js`: البحث والتنقل والتكبير والانطباعات المحلية والربط الاختياري.
- `issues.js`: قائمة الأعداد وعناوينها وروابط صورها.
- `config.js`: إعدادات الخدمات الاختيارية، فارغة افتراضيًا.
- `assets/pages`: الصفحات الكاملة.
- `assets/thumbs`: الأغلفة المصغّرة.
- `.nojekyll`: تعطيل معالجة Jekyll غير المطلوبة.

## إضافة عدد

ضع الصورة الكاملة والمصغرة في المجلدين المناسبين ثم أضف كائنًا إلى مصفوفة `ISSUES` في `issues.js` بنفس البنية ورقم فريد. ترتيب القائمة الأصلية تصاعدي ويُستخدم للتنقل. راجع العنوان والصورة قبل النشر.

## التحقق وحدود التسليم

تم فحص صياغة JavaScript، وعدد الأعداد، ووجود الصور، ومطابقة بكسلات النسخ الكاملة مع المرفقات. لم تُفعّل خدمات خارجية ولم يُنشر مستودع نيابة عنك. يلزم اختبار المتصفح بعد النشر، بما فيه الهاتف والتنقل بلوحة المفاتيح والروابط والإحصاءات عند إعدادها. لا يوجد اختبار بصري آلي للمتصفح في بيئة التسليم الحالية.

## تحديث الأعداد
أضيفت الأعداد 21 إلى 25 بصورها الأصلية، فأصبح المجموع 24 عددًا. لرفع التحديث إلى مستودع قائم استبدل الملفات بالمحتويات المحدّثة، مع الاحتفاظ بإعداداتك الخاصة في config.js إن كنت عدّلتها.

## تحديث الشعار والخط
استُبدلت صورة الغلاف بجانب عنوان الواجهة بالشعار المرفق كاملًا دون قص. يؤدي النقر عليه إلى فهرس الأعداد. وُحّد خط نصوص الواجهة والأزرار والحقول إلى Noto Sans Arabic، بوزنين 400 و700 مضمّنين محليًا مع ترخيص OFL. لا يحتاج الخط اتصالًا بخدمة خطوط خارجية. النصوص المدمجة داخل صور الصحائف والشعار تحتفظ بخطوطها الأصلية.

## استكمال العدد الثالث وخانة الإحصاءات
أضيف العدد الثالث في ترتيبه بين العددين الثاني والرابع وأصبح المجموع 25 عددًا. خانة إحصاءات الزوار ظاهرة دائمًا في قسم عن الصحيفة؛ تعرض حالة عدم التفعيل بدل أي رقم وهمي. عند ضبط goatcounterCode وتفعيل publicCounter والعرض العام لدى الخدمة، تعرض إجمالي مشاهدات الصفحات. هذا ليس حصرًا للأشخاص الفريدين. لا يزال تفعيل الحساب مطلوبًا من مالك المنصة.
